Event Data Transformation

This project focuses on transforming semi-structured event data (JSON format) into structured, analytics-ready tabular datasets. The goal is to design a clean and reproducible ETL pipeline that converts raw application event logs into curated CSV tables for downstream analytics and business intelligence use cases.

The dataset originates from Chama’s mobile applications and backend systems, where event payloads are stored as nested JSON strings. These payloads must be flattened, cleaned, and standardized to ensure data quality and usability.

🎯 Objective

Transform the raw case.json event dataset into three structured CSV tables:

CuratedOfferOptions.csv

DynamicPriceOption.csv

DynamicPriceRange.csv

The transformation pipeline includes:

JSON parsing and flattening

Schema standardization

Type casting and formatting

Timezone conversion (UTC → Brazil timezone UTC-3)

Data quality enforcement

Column selection and restructuring

📂 Input Data

File: case.json

Format: Nested JSON with embedded payload string

Event Types:

DynamicPrice_Result

CuratedOfferOptions

DynamicPriceOption

Example record:

{
  "EnqueuedTimeUtc": "2021-09-05 08:04:08 UTC",
  "EventName": "DynamicPrice_Result",
  "Payload": "{\"provider\":\"ApplyDynamicPriceRange\",\"offerId\":\"...\",\"algorithmOutput\":{...}}"
}
🏗️ ETL Pipeline Design
Step 1 — Data Ingestion

Load JSON event data using Python

Parse nested JSON payload strings

Step 2 — Data Transformation

Flatten hierarchical structures

Normalize schema across event types

Extract relevant attributes

Convert timestamps to Brazilian timezone

Format dates as DD/MM/YYYY

Step 3 — Data Structuring

Generate three analytics-ready datasets:

CuratedOfferOptions.csv

Contains curated dealer pricing options and decision outcomes.

DynamicPriceOption.csv

Contains best price outputs generated by dynamic pricing algorithms.

DynamicPriceRange.csv

Contains recommended pricing ranges based on pricing optimization models.

Step 4 — Data Output

Export clean datasets in CSV format for analytics consumption.
